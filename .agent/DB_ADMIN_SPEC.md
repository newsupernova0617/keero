# Admin 데이터베이스 관리 페이지 개선 기획안

## 📋 현재 상태 (Current State)

### 기존 기능

- **통계 조회**: 게시글, 댓글, 사용자 총 수
- **사이트별 통계**: 각 사이트별 게시글 수
- **최근 게시글**: 최근 20개 게시글 조회 및 개별 삭제
- **데이터 정리**: 30일 이상 된 게시글 일괄 삭제

### 현재 DB 스키마

```
posts (게시글)
images (이미지/미디어)
users (사용자)
comments (댓글)
likes (좋아요)
bookmarks (북마크)
reports (신고)
highlights (주간 하이라이트)
```

---

## 🎯 개선 목표 (Goals)

1. **완전한 CRUD 기능**: 모든 테이블에 대해 생성, 읽기, 수정, 삭제 가능
2. **고급 필터링 및 검색**: 날짜, 사이트, 상태 등 다양한 조건으로 데이터 검색
3. **벌크 작업**: 여러 항목을 한번에 수정/삭제
4. **데이터 백업/복원**: SQLite DB 백업 및 복원 기능
5. **SQL 쿼리 실행**: 안전한 방식의 직접 SQL 실행 (읽기 전용/쓰기 구분)
6. **테이블 관계 시각화**: 데이터 간 연관 관계 확인
7. **성능 모니터링**: DB 크기, 쿼리 속도 등 모니터링

## 🏗️ 구조 설계 (Architecture)

### 1. 페이지 구조 (Route Structure)

```
/admin/database
├── /tables              (모든 테이블 목록 및 스키마 정보)
│   ├── /posts           (게시글 테이블 관리)
│   ├── /images          (이미지 테이블 관리)
│   ├── /users           (사용자 테이블 관리)
│   ├── /comments        (댓글 테이블 관리)
│   ├── /likes           (좋아요 테이블 관리)
│   ├── /bookmarks       (북마크 테이블 관리)
│   ├── /reports         (신고 테이블 관리)
│   └── /highlights      (하이라이트 테이블 관리)
├── /query               (SQL 쿼리 실행)
├── /backup              (백업 및 복원)
└── /monitor             (성능 모니터링)
```

### 2. 컴포넌트 구조

```
/lib/components/admin/database/
├── TableList.svelte           (테이블 목록)
├── TableViewer.svelte         (테이블 데이터 뷰어)
├── DataEditor.svelte          (데이터 편집기)
├── BulkActions.svelte         (벌크 작업 UI)
├── QueryExecutor.svelte       (SQL 쿼리 실행기)
├── BackupManager.svelte       (백업 관리)
├── FilterPanel.svelte         (고급 필터)
└── RelationshipDiagram.svelte (관계도)
```

4. **벌크 작업 구현**
   - 선택한 항목들 일괄 삭제

## 🔐 보안 고려사항

### 1. 인증 및 권한

- ✅ 이미 구현됨: `requireAdmin` 미들웨어
- 추가 필요: 민감한 작업 시 비밀번호 재확인 (백업 복원, 쓰기 모드 쿼리 등)

### 2. SQL 인젝션 방지

- ✅ Drizzle ORM 사용으로 기본 방지
- ⚠️ 직접 SQL 실행 시:
  - 파라미터 바인딩 강제
  - 위험한 키워드 감지

### 3. CSRF 방어

- ✅ SvelteKit의 기본 CSRF 토큰 사용
- 모든 폼 액션에서 토큰 검증

### 4. 감사 로그 (Audit Log)

- 누가, 언제, 무엇을 수정했는지 기록
- 새 테이블 필요: `audit_logs`
  ```sql
  CREATE TABLE audit_logs (
    id INTEGER PRIMARY KEY,
    user_id INTEGER,
    action TEXT,      -- 'INSERT', 'UPDATE', 'DELETE', 'QUERY'
    table_name TEXT,
    record_id INTEGER,
    old_value TEXT,   -- JSON
    new_value TEXT,   -- JSON
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
  );
  ```

## 📊 데이터 모델 확장

### 새로운 테이블 추가

#### 1. `audit_logs` (감사 로그)

```typescript
export const auditLogs = sqliteTable("audit_logs", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  user_id: integer("user_id").references(() => users.id),
  action: text("action").notNull(), // 'create', 'update', 'delete', 'query'
  table_name: text("table_name").notNull(),
  record_id: integer("record_id"),
  old_value: text("old_value"), // JSON string
  new_value: text("new_value"), // JSON string
  query: text("query"), // SQL 쿼리 (query 액션인 경우)
  created_at: text("created_at").default(sql`CURRENT_TIMESTAMP`),
});
```

#### 2. `backup_settings` (백업 설정)

```typescript
export const backupSettings = sqliteTable("backup_settings", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  enabled: integer("enabled", { mode: "boolean" }).default(false),
  frequency: text("frequency").default("daily"), // 'daily', 'weekly', 'monthly'
  time: text("time").default("03:00"), // HH:MM
  retention_days: integer("retention_days").default(30),
  last_backup_at: text("last_backup_at"),
  updated_at: text("updated_at").default(sql`CURRENT_TIMESTAMP`),
});
```

## 🎨 UI 라이브러리 및 도구

### 사용할 라이브러리

1. **shadcn-svelte**: ✅ 이미 사용 중 (Button, Card, Table 등)
2. **Lucide Icons**: ✅ 이미 사용 중
3. **추가 필요**:
   - **TanStack Table (Svelte)**: 강력한 데이터 테이블
   - **CodeMirror 6** 또는 **Monaco Editor**: SQL 편집기
   - **date-fns**: 날짜 처리
   - **zod**: 폼 유효성 검사
   - **Chart.js** 또는 **Recharts**: 그래프

### 설치 명령어

```bash
npm install @tanstack/svelte-table
npm install codemirror
npm install date-fns
npm install zod
npm install chart.js
```

## 📝 추가 고려사항

### 1. 모바일 대응

- 데이터 테이블: 모바일에서 가로 스크롤 또는 카드 뷰 전환
- 편집 모달: 전체 화면 모달

### 2. 다크 모드

- ✅ shadcn-svelte가 자동 지원
- SQL 편집기도 다크 테마 적용 필요

### 3. 실시간 업데이트

- WebSocket 또는 Server-Sent Events로 다른 관리자의 변경사항 실시간 반영
- (선택적, 낮은 우선순위)

### 4. 데이터 검증

- 스키마 변경 시 마이그레이션 자동 생성
- 제약 조건 위반 시 명확한 에러 메시지

### 5. Export/Import

- CSV, JSON, SQL dump 형식 지원
- Excel 형식도 고려 가능 (xlsx 라이브러리)
