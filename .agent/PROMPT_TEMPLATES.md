## 💡 효과적인 프롬프트 작성 팁

### ✅ DO (해야 할 것)
1. **구체적으로 작성**: "댓글 기능" → "계층형 댓글 시스템 (답글 지원, 좋아요, 수정/삭제)"
2. **기존 코드 참조**: "webapp/src/routes/post/[id]/+page.svelte 스타일 참고"
3. **기술 스택 명시**: "Svelte 5 Runes, TypeScript, Drizzle ORM 사용"
4. **제약사항 명시**: ".agent/SVELTE_GUIDE.md 규칙 준수"
5. **예시 제공**: "이런 형태로 동작해야 함: [예시]"

### ❌ DON'T (하지 말아야 할 것)
1. **모호한 요청**: "좀 더 예쁘게 만들어줘"
2. **기술 스택 누락**: "댓글 기능 만들어줘" (어떤 문법으로?)
3. **한 번에 너무 많은 요청**: 여러 기능을 한 번에 요청
4. **맥락 없는 질문**: 관련 파일이나 상황 설명 없음

### 예시 1: 북마크 페이지 추가

3. 페이지네이션 (24개씩)
4. 북마크 해제 기능

참고 파일:

- webapp/src/routes/+page.svelte (그리드 레이아웃)

- 현재 사용자의 북마크만 조회

- Svelte 5 Runes
- TypeScript
- Drizzle ORM

규칙:

- .agent/SVELTE_GUIDE.md 준수

### 예시 2: 댓글 좋아요 버그 수정
```

webapp/src/lib/components/Comment.svelte에서
댓글 좋아요 버튼이 클릭 후 상태가 즉시 반영되지 않는 버그를 수정해줘.

현재 상황:

- 좋아요 버튼 클릭 시 서버 요청은 성공
- 하지만 UI가 새로고침 전까지 업데이트 안 됨

기대 동작:

- 클릭 즉시 UI 업데이트 (낙관적 업데이트)
- 서버 요청 실패 시 롤백

관련 코드:

- Comment.svelte (클라이언트)
- post/[id]/+page.server.ts (toggleCommentLike 액션)

규칙:

- Svelte 5 $state 사용
- 기존 로직 최대한 보존
- 에러 핸들링 추가

```
